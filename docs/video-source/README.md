# Editable HyperFrames demo

Requires Node 22+ and FFmpeg/ffprobe on PATH. Run `npm run check`, `npm run dev` (Studio), or `npm run render -- --quality delivery --output demo.mp4`. CLI pinned to 0.8.219 used for this update. The project retains earlier narration; browser capture and the two complete voice samples are from 30 October 2026. Screens are genuine, recorded at 5 fps and edited for pace. Paid settings are shown without a real key; paid speech is not demonstrated. All generated voices are synthetic. No human listener certification.
