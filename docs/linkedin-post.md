# LessonVoice showcase draft — 30 October 2026

Status: prepared, not published in this update. Attach lessonvoice-update-20261030.mp4, not an older render.

A lesson should be easy to listen to—and easy for a teacher to review.

I built LessonVoice to turn English or Urdu teaching notes into editable audio chapters, transcripts, teacher-written questions and a downloadable learning pack.

The latest update keeps local OmniVoice as the default, increases synthesis to 64 steps, and adds an optional ElevenLabs paid API mode for users who want to compare another voice. The README explains API keys, voice IDs, costs and privacy.

I tested real English/Urdu generation in Chrome, Urdu playback and ZIP downloads. The automated suite now passes 55 tests. This video shows the running app and includes actual generated voice samples.

Pronunciation still needs teacher review, especially Urdu and mixed-language text. Local model weights have noncommercial restrictions. Paid synthesis requires your own funded key and has not been live-tested in this update.

Code and setup: https://github.com/ismailiqbal2773/LessonVoice
