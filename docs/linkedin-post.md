# LessonVoice — published 30 October 2026

Verified live: https://www.linkedin.com/feed/update/urn:li:activity:7521785671770861569/

Your lesson is ready. Can your students listen to it?

I built LessonVoice to turn English or Urdu teaching notes into an audio learning pack—with the teacher in control.

The workflow is simple:
Write → split into chapters → edit → generate → listen → export.

Inside the pack:
• Audio chapters and matching transcripts
• Teacher-written questions and a separate answer key
• A simple HTML player and downloadable WAV files

Local OmniVoice is the default after model installation. The latest update uses 64 synthesis steps and adds an optional ElevenLabs API mode, with clear setup instructions and explicit consent before sending spoken text to the provider.

This 32-second demo shows the real running app and includes actual English and Urdu voice samples. I checked generation, Urdu playback and ZIP downloads in Chrome; 55 automated tests pass.

The next quality gate is still human listening. Urdu pronunciation and mixed-language text need review. Paid synthesis requires your own key and credits and has not been live-tested in this update. Local model weights have noncommercial restrictions.
